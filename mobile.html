Mockup · PRD v0.3 · Day trip

Mobile field app

One seamless day trip: Load at plant → deliver / collect empties & money → Return to plant (unsold + empties). Visits run only while a trip is open.

How to try it

  1. Tap Reset trip below → Home shows Load at plant.
  2. Load from plant → set qtys → Start trip.
  3. New Visit → Given / Empty back → money → Save (van stock updates).
  4. Home → Return → confirm unsold + empties → close trip.

Persona: Tikesh. Day trip = Load → Deliver → Return. See PRD.
